如何乾淨截下推文，不帶頁面雜訊

想把推文存成圖片放進簡報、電子報或群組聊天時，一般截圖常常會混進底下的回覆串、側邊欄與發糊的文字。把推文轉成圖片常見有三種做法，各自都有明確取捨。

  1. 手機內建截圖

    按下 iOS 或 Android 實體鍵截圖，再手動裁掉狀態列、導覽圖示與底下露出的第一則回覆。單則短推文確實方便，但代價是解析度受限於螢幕、邊距不齊，遇到同作者長串只能滑動截好幾張再手工拼接。

  2. 瀏覽器選區截圖

    在桌機上用系統截圖工具或瀏覽器快捷鍵框選貼文區域。構圖比手機好掌握一些，但代價依然受限於顯示器 DPI、容易截進瀏覽器介面或懸停狀態，遇到引用卡片或多圖格線接近視窗邊緣時還得反覆重裁。

  3. 直接渲染成卡片

    不再對著螢幕拍像素，而是讀取貼文的文字、媒體與長串結構，在乾淨的畫布上重新排版輸出。代價是常見的線上網頁工具通常要求把貼文網址貼給第三方伺服器，受限於 API 額度，還常附帶浮水印或長串斷裂。

PostPress 採用第三種做法，並全程在你的瀏覽器本機完成：在任何 X 貼文上點一下按鈕（或按 Alt + C），挑選喜歡的材質，就能把銳利的 3× PNG 直接複製到剪貼簿——自動過濾回覆與廣告，不經伺服器、免登入。

長文、引用與多圖格線，完整保留。

X 長文會帶出封面圖與導語；引用貼文依材質填充或描邊；一到二十張圖片在格線中維持各自比例，第五張起改為四欄多列（填滿模式則裁成正方形）。

「不是濾鏡，而是紙張、格線與字體的恰當比例。」

  • 長文 封面、欄目名稱、標題與導語一次帶出。
  • 引用 填充或描邊，跟隨當前材質。
  • 圖片 一到二十張保留各自原始比例而不硬裁成方塊；五張起四欄排列，選擇填滿時才裁成正方形。

八個開關，一座工作台。

材質、畫幅、背景、頁尾細節、作者模糊與匯出解析度都集中在這個 Studio 視窗裡；調整一項，左側預覽立刻同步更新。偏好設定會自動記住，日常只要打開再按「複製圖片」即可。

從頭到尾都在本機執行。

沒有帳號、沒有伺服器、沒有遙測。排版在隔離的 Shadow DOM 中完成，匯出由瀏覽器自己的畫布繪製。除了向 X 的圖片主機取得卡片裡本來就有的圖片之外，不會有任何資料離開你的電腦。

不讀取你的時間軸、不需要 X 帳號，也不使用 X API。與 X Corp. 無關聯。

  • clipboardWrite 只在你按下「複製」時，將完成的圖片寫入剪貼簿。
  • storage 記住你選擇的材質、畫幅與開關；僅儲存在本機。
  • *.twimg.com 抓取卡片內的圖片。沒有此權限，畫布無法讀取跨來源圖片。

常見問題

八個真實問題，解答就在右側。

為什麼不直接截圖就好？

手動裁切截圖得閃開底下的回覆、把長串滾動截圖後再拼起來，而且受限於螢幕 DPI 與瀏覽器邊框。點一下 PostPress，整則貼文或長串會直接依材質規則排好版，把銳利的 3× 圖片放進剪貼簿，隨時貼上。

長卡片發到動態牆會被壓糊嗎？

單則貼文以 3× 匯出。很長的長串預設以 2× 匯出以控制在尺寸上限內；若縮放後文字會過小，面板會先提醒並建議拆分。匯出設定中也提供全域 3× 開關。

需要登入或綁定 X 嗎？

不需要。沒有帳號系統，只讀取眼前頁面已經渲染好的內容，完全不碰任何憑證。

會有任何資料被上傳嗎？

不會。圖片只寫入剪貼簿與你的磁碟；關閉預覽視窗即釋放其餘資料，不保存任何貼文內容。

可以商業使用嗎？

軟體本身採用 GPL-3.0-or-later 授權，可自由用於商業用途。卡片中的文字與圖片仍屬於原作者；轉載前請自行確認授權。

支援哪些瀏覽器？

Chrome 與 Edge（Chrome 111 起，Manifest V3）。尚未支援 Firefox 與 Safari——本擴充功能基於 Chromium 的擴充 API 開發。

怎麼只截推文正文、不把底下的回覆截進去？

點擊貼文上的 PostPress 卡片按鈕（或游標懸停按 Alt + C）。PostPress 只讀取該則貼文或同作者連續長串，會自動濾除廣告與第三方回覆；若長串中某則不想顯示，複製前點一下即可排除。

能把推文直接轉成 PNG 圖片嗎？

可以。PostPress 會在瀏覽器本機渲染卡片，並將 3× PNG 直接複製到剪貼簿（或下載 PNG 檔到磁碟）。超長串預設為 2× 以避開尺寸上限，也可以在匯出設定中切換為 3×。
