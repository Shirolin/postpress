スレッドは自動でつながる。

同じスレッド内のポストは投稿者と時刻から自動で連結され、広告や無関係なリプライは除外されます。取得は 2 段階：まず X 本体の GraphQL キャッシュを読み、キャッシュがなければ描画済み DOM から取得します。外したいポストはワンクリックで除外できます。

余計な表示なしでツイートをきれいにスクショする方法

資料やニュースレター、チャットで共有しようとツイートをスクショしても、リプライ欄やサイドバー、にじんだ文字まで写り込みがちです。ツイートを画像化する主な方法は 3 つあり、それぞれ明確なトレードオフがあります。

  1. スマホのスクリーンショット

    iOS や Android の物理ボタンで撮影し、ステータスバーやナビゲーション、直下の最初のリプライを手で切り抜きます。単発の短いポストには手軽ですが、画面解像度以上に鮮明にならず、余白も不揃いで、長いスレッドは何枚も撮って手でつなぐ必要があります。

  2. ブラウザの範囲選択キャプチャ

    デスクトップで OS の切り取りツールやブラウザのショートカットを使い、ポストの周囲をドラッグして囲みます。スマホよりは構図を調整しやすいものの、モニターの DPI 依存やブラウザ枠・ホバー表示の映り込みは避けられず、引用カードや画像グリッドが画面端にあると毎回切り直しになります。

  3. カードとして再描画する

    画面のピクセルをそのまま撮るのではなく、テキスト・メディア・スレッド構造を読み取ってクリーンなキャンバス上に組み直します。ただしオンラインの Web ツールは、ツイート URL を外部サーバーへ送る必要があったり、API 制限や透かし、スレッド崩れに悩まされがちです。

PostPress は 3 番目の方法をブラウザ内だけで完結させます。任意の X ポストのカードボタンを押す（または Alt + C）だけで、テーマを選んで鮮明な 3× PNG をクリップボードへ直接コピー。リプライや広告を除外し、サーバー送信もログインも不要です。

記事・引用・画像グリッドもそのまま。

X 記事はカバー画像とリード文を引き出し、引用ポストはテーマに合わせて塗りまたは枠線で表現。1〜20 枚の画像は比率を保ったままグリッド配置され、5 枚以上は 4 列で並びます（塗りつぶしモードでは正方形にトリミング）。

「フィルターではない。紙と罫線と活字の比率だ。」

  • 記事 カバー、キッカー、タイトル、冒頭文をまとめて美しく配置。
  • 引用 塗りまたは枠線をテーマに合わせて切り替え。
  • 画像 1〜20 枚まで元の縦横比を保って配置（5 枚以上は 4 列表示）。塗りつぶし指定時は正方形に整列。

8 つのスイッチを、ひとつの Studio に。

テーマ、キャンバス比率、背景、フッター要素、投稿者ぼかし、書き出し解像度をすべてこの Studio モーダルに集約。変更すると左側のプレビューが即座に追従し、設定は保存されるため次回からは開いてコピーするだけです。

最初から最後まで、すべてあなたの端末内で。

アカウント不要、サーバー不要、テレメトリ一切なし。組版は隔離された Shadow DOM 内で行われ、書き出しはブラウザ自身のキャンバスが描画します。カード内の画像を X の画像サーバーから取得する以外に、外部へ何も送信しません。

タイムラインは読み取らず、X アカウントも X API も不要です。X Corp. とは無関係です。

  • clipboardWrite 「画像をコピー」を押したときだけ、生成した画像をクリップボードへ書き込みます。
  • storage 選んだテーマ、キャンバス、各スイッチをローカルに記憶します。
  • *.twimg.com カード内の画像を取得します。これがないとキャンバスはクロスオリジン画像を読み込めません。

Chrome ウェブストアから追加 GitHub リポジトリを開く

GPL-3.0-or-later ライセンスで公開。改変して再配布する場合は同一ライセンスに従ってください。

開発者向け：ソースからビルド（3 ステップ）

  1. ビルド

    リポジトリをクローンし、依存関係をインストールしてビルドします。成果物は dist/ に出力されます。

  2. 読み込み

    chrome://extensions を開き、デベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」から dist/ を選択します。

  3. 使う

    任意のポストのカードボタンを押す（またはホバーして Alt + C）→「画像をコピー」をクリックしてどこにでも貼り付けられます。

git clone https://github.com/Shirolin/postpress.git
cd postpress
pnpm install
pnpm run build   # → dist/

よくある質問

8 つの実用的な質問と回答をまとめました。

普通にスクリーンショットを撮るのではダメですか？

手動のスクショではリプライを避けて切り抜いたり、長いスレッドを複数回に分けて繋ぎ合わせたりする必要があり、画面の DPI やブラウザの枠に左右されます。PostPress なら 1 クリックでテーマ規則に沿って組み直し、鮮明な 3× 画像を直接クリップボードへコピーできます。

縦に長いカードはタイムラインでぼやけませんか？

単体ポストは 3× で書き出します。非常に長いスレッドはサイズ上限内に収めるため既定で 2× になり、小さすぎて読みにくくなる場合はパネルが分割を促します。書き出し設定で常時 3× にすることも可能です。

X へのログインや連携は必要ですか？

不要です。アカウント機能自体がなく、今開いているページにすでに描画された内容だけを読み取るため、認証情報には一切触れません。

画像やテキストがどこかへアップロードされますか？

されません。画像はクリップボードと端末のストレージにのみ書き出され、プレビューを閉じればメモリから解放されます。ポスト内容の保存も行いません。

商用利用は可能ですか？

ソフトウェア自体は GPL-3.0-or-later であり商用利用できます。ただしカード内の文章や写真の著作権は元の投稿者に帰属するため、再配布時はご自身でご確認ください。

どのブラウザで動作しますか？

Chrome 111 以降の Chrome と Edge（Manifest V3）に対応しています。Chromium の拡張機能 API を使用しているため、Firefox と Safari にはまだ対応していません。

リプライを含めずにツイートだけをスクショするには？

対象のポスト上にある PostPress カードボタンを押す（またはホバーして Alt + C を押す）だけです。そのポスト、または同一投稿者の連続スレッドだけを読み取り、広告や第三者のリプライを自動で除外します。スレッド内で不要なポストがあれば、コピー前に 1 クリックで除外できます。

ツイートを PNG 画像に変換できますか？

はい。PostPress はブラウザ内でカードをローカル描画し、3× の PNG をそのままクリップボードへコピー（またはディスクへ PNG ファイルとして保存）します。非常に長いスレッドは上限対策として既定 2× になりますが、書き出し設定から 3× を選ぶこともできます。
